## Steps to reproduce
1. Log in with valid credentials.
2. Click Logout.
3. Click the browser Back button.

## Expected result
The login page stays on screen; the secure page is not shown from history.

## Actual result
The previously logged-in page is displayed again after logout.

## Impact
The page can be cached and shown after the session ended; on a shared computer the next person can read it. Fix: send no-store cache headers on secure pages.
