## Steps to reproduce
1. Enter a valid username with a wrong password and click Login. Note the message.
2. Enter a username that does not exist with any password and click Login. Note the message.

## Expected result
Both cases show the same generic message, for example 'Invalid username or password'.

## Actual result
The two messages are different, so an attacker can tell which usernames are real.

## Impact
Makes targeted password guessing easier.
