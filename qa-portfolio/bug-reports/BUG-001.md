## Steps to reproduce
1. Make sure you are logged out (or open a private window).
2. Paste the URL of the page shown after login into the address bar.
3. Press Enter.

## Expected result
The user is redirected to the login page and the secure content is not shown.

## Actual result
The secure page opens and its content is shown without any login.

## Impact
Broken access control: anyone with the URL can reach protected content.
